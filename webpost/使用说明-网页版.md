## 一、页面长什么样

```
┌───────────────────────────────────────────────────────┐
│ 标题输入框 │ 版块 ▾ │ 分类 ▾ │ 账号 ▾ │ 🔄刷新版块 │ 导入/导出 │ 未登录 ✓ │
├──────────────────────────┬────────────────────────────┤
│  工具栏                  │                            │
│  ─────────────────────── │      实时预览              │
│  正文编辑区（在这写）     │   （就是发布后的效果）      │
├──────────────────────────┴────────────────────────────┤
│  字数 / 图片数      [填入论坛编辑器]  [直接发布 🚀]     │
└───────────────────────────────────────────────────────┘
```

**左边写，右边看** —— 右边预览的就是论坛上真正的排版效果；底部实时显示字数和图片数。

## 二、工具栏按钮

选中文字再点按钮，改的是选中的那部分；没选中就影响光标位置往后输入的内容。

| 按钮 | 作用 | 什么时候用 |
|---|---|---|
| **B** | 加粗 | 重点词句 |
| *I* | 斜体 | 轻微强调 |
| <u>U</u> | 下划线 | 强调、或论坛里常用的重点句 |
| 大标题 / 小标题 | 文章里的大小标题 | 长帖分层，读者好扫读 |
| 正文 | 取消标题，回到普通段落 | 标题用错了退回普通文字 |
| • 列表 / 1. 列表 | 无序 / 编号列表 | 步骤、要点罗列 |
| ❝ 引用 | 引用块 | 引用别人的话、官方说明 |
| &lt;/&gt; 代码 | 代码块（能保留缩进） | 贴命令、日志、配置 |
| ▦ 表格 | 插入表格（可填行列数） | 参数对比、清单 |
| 🔗 链接 | 插入网址链接 | 只支持 http/https 链接 |
| — 分割线 | 一条横线 | 段落之间分隔 |
| ● ● ● ● ● | 五种字体颜色（红/绿/蓝/橙/黑） | 关键数字、提醒、结论 |
| 🖼 插入图片 | 从电脑选图片插入 | 不想用粘贴时 |

**图片调顺序**：点一下正文里的图片，会弹出小工具条 —— 「↑ 上移」「↓ 下移」「🗑 删除」。
插错图不用清空重写；按住图片拖到别的位置也能换顺序。按 Esc 收起工具条。

## 三、顶部区域

| 位置 | 作用 |
|---|---|
| 标题输入框 | 右边 `x/40` 是字数提示，超过 40 字会标黄（论坛会截断） |
| 版块下拉 | 选发到哪个版块；带 ✗ 的表示**当前账号在这个版块发不了帖** |
| 分类下拉 | 主题分类，**要先选版块才能用**（分类跟着版块变）；不选也能发 |
| 账号下拉 | 切换账号 / 登录新号 / 重新登录 / 移除某个号 |
| 🔄 刷新版块 | 重新扫一遍各版块的发帖权限（换账号后、或权限看着不对时用） |
| 📚 片段库 | 常用段落一键插入，可新建/改名/删除 | 每次都要写的开头结尾、设备信息表、免责声明 |
| 导入 Markdown | 把 .md 文件（和它的配图）导进来继续编辑 |
| 导出 Markdown | 把写好的内容存成 .md 文件（可以拿去别处发） |
| 🩺 体检 | 检查官方发帖页是不是还能用；发不了帖时先点它自查 |
| 未登录 / 昵称 | 显示当前登录身份 |

## 四、中间：写与看

- 左边编辑区：直接打字；工具栏改排版
- 右边预览区：实时显示发布后的效果（第一次打开有引导提示）
- 底部状态栏：字数、图片数、草稿保存时间

---

## 五、插图三种方式

| 方式 | 怎么做 |
|---|---|
| **粘贴**（最常用） | 截图后按 `Ctrl+V`，一次粘多张也全都进来 |
| 拖拽 | 图片文件直接拖进编辑区 |
| 按钮 | 点工具栏「🖼 插入图片」选文件 |

拖进来的不是图片时不会弄丢内容，只会提示一句。特别大的图（超过 600KB 又很宽）会自动压一下，读者加载更快。

---

## 六、草稿

- 自动保存，按标题分开存（换标题 = 另一份草稿）
- 底部「保存草稿」可以手动存一次
- 顶部草稿下拉切换之前的稿子；**没有草稿时它自动隐藏**
- 「清空」会清掉编辑区，当前标题有草稿时会问要不要一起删

---

## 七、底部两个发布按钮

| 按钮 | 结果 |
|---|---|
| **填入论坛编辑器（不发布）** | 内容填到官方发帖页，你自己检查后手动点发表 —— 第一次用建议先走这个 |
| **直接发布 🚀** | 自动发表，完成后给你帖子链接（会先弹确认框写明版块/标题/字数图数） |

发布过程中弹出的浏览器窗口在自动操作，**这段时间别动它**。

---

## 八、右下角的绿色小球

反馈用的：点它 → 「📦 下载诊断包」→ 按提示发给作者（微信搜一搜 / 添加公众号「很多问题的小明同学」）。
包里只有环境、发帖页、版块权限三项结论，**不含账号密码、昵称、草稿和本机文件**。

---

## 九、几个小提醒

1. **先填标题再写内容** —— 草稿按标题存，标题写清楚以后好找回来
2. 顶部那条绿色小提示（插图用法 / 排错入口）看腻了可以点右边的 **×** 关掉，以后不再显示
3. 第一次发，建议用「填入论坛编辑器」走一遍，亲眼确认排版没问题
4. 换账号后版块权限会重新扫，稍等一会儿再用
5. 任何弹窗都可以按 **Esc** 取消
6. 内容会存在本机草稿里，写一半关掉也不怕
